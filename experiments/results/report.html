How it decides

  1. 1

    Learn normal

    One clean 3-minute run. Normal was 0% errors (wiggle 2%) and p95 97 ms (wiggle 5 ms).

  2. 2

    Score every 5 s

    For each server: how many wiggles worse than normal is it now? More than 3 counts as odd.

  3. 3

    Two in a row

    Only two odd samples in a row raise an alert, so one random blip never does.

A crash is the health check’s job

A killed server is caught in 1 s and gets no traffic after that, so the AI has nothing to judge. That is fine.

No false alarms

Z-score false alarms across all runs: 0, even when one odd sample is enough. Two in a row stays the default as a safety margin; it costs 5 s.

The forest adds nothing yet

With only two numbers per server, Isolation Forest finds the same faults as a z-score. It should help once we add more numbers.
